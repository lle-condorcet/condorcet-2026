🏷️ HTML Tags & HTML Helpers

Cheatsheet complète - Balises HTML vs Équivalents Razor en C#

📋 Formulaires

FORM Formulaire

Conteneur pour envoyer des données

❌ HTML Simple

<form action="/users/create" method="POST">
  <input type="hidden" name="__RequestVerificationToken" />
</form>

✅ HTML Helper

@Html.BeginForm("Create", "Users")
{
    @Html.AntiForgeryToken()
}

// Ou avec Razor Pages:
<form method="post">

INPUT Champ texte

Saisie textuelle simple

❌ HTML Simple

<input type="text" name="Name" value="John" />

✅ HTML Helper

@Html.TextBoxFor(m => m.Name)

INPUT HIDDEN Champ caché

Valeur non visible à l'utilisateur

❌ HTML Simple

<input type="hidden" name="Id" value="5" />

✅ HTML Helper

@Html.HiddenFor(m => m.Id)

INPUT PASSWORD Mot de passe

Champ avec caractères masqués

❌ HTML Simple

<input type="password" name="Password" />

✅ HTML Helper

@Html.PasswordFor(m => m.Password)

INPUT EMAIL Email

Validation email native

❌ HTML Simple

<input type="email" name="Email" />

✅ HTML Helper

@Html.TextBoxFor(m => m.Email, 
    new { type = "email" })

INPUT NUMBER Nombre

Champ numérique

❌ HTML Simple

<input type="number" name="Age" />

✅ HTML Helper

@Html.TextBoxFor(m => m.Age,
    new { type = "number" })

INPUT CHECKBOX Case à cocher

Option booléenne

❌ HTML Simple

<input type="checkbox" name="IsActive" />

✅ HTML Helper

@Html.CheckBoxFor(m => m.IsActive)

TEXTAREA Zone de texte

Texte multi-lignes

❌ HTML Simple

<textarea name="Description" rows="5"></textarea>

✅ HTML Helper

@Html.TextAreaFor(m => m.Description, 
    new { rows = 5 })

SELECT Liste déroulante

Choix parmi une liste

❌ HTML Simple

<select name="RoleId">
  <option value="1">Admin</option>
  <option value="2">User</option>
</select>

✅ HTML Helper

@Html.DropDownListFor(m => m.RoleId,
    (IEnumerable<SelectListItem>)ViewBag.Roles)

INPUT BUTTON Bouton

Action ou soumission

❌ HTML Simple

<button type="submit">
  Envoyer
</button>

✅ HTML Helper

✅ Validation

Message d'erreur

Afficher les erreurs de validation

❌ HTML Simple

<div class="error">
  Le nom est requis
</div>

✅ HTML Helper

@Html.ValidationMessageFor(
    m => m.Name)

Résumé des erreurs

Lister toutes les erreurs de validation

❌ HTML Simple

<div class="validation-errors">
  @foreach (var error in ModelState.Values.SelectMany(v => v.Errors))
  {
    <p>@error.ErrorMessage</p>
  }
</div>

✅ HTML Helper

@Html.ValidationSummary()

Classe CSS de validation

Appliquer une classe au champ invalide

❌ HTML Simple

<input type="text" 
    class="form-control is-invalid">

✅ HTML Helper

@Html.TextBoxFor(m => m.Name,
    new { 
        @class = ViewData.ModelState["Name"]?.Errors.Any() == true ? "is-invalid" : ""
    })

🎨 Scripts et Styles

Lien CSS

Inclure une feuille de styles

❌ HTML Simple

<link rel="stylesheet" 
    href="/css/style.css" />

✅ HTML Helper

@Html.Raw("<link rel='stylesheet' href='/css/style.css' />")

// Ou utiliser Asp-href
<link rel="stylesheet" href="/css/style.css" />

Balise Script

Inclure un fichier JavaScript

❌ HTML Simple

<script src="/js/app.js"></script>

✅ HTML Helper

<script src="/js/app.js"></script>

// Ou avec Tag Helpers
<script asp-src="/js/app.js"></script>

Style inline

Appliquer du CSS inline

❌ HTML Simple

<div style="color: red; font-size: 16px;">

✅ HTML Helper

<div style="color: red; font-size: 16px;">

// Mieux: utiliser les classes CSS
<div class="text-danger fs-5">

🏷️ Tag Helpers (ASP.NET Core)

asp-for

Lier un élément à une propriété

❌ HTML Simple

<input type="text" name="Name" />

✅ Tag Helper

<input asp-for="@Model.Name" />

asp-action & asp-controller

Générer les URLs dynamiquement

❌ HTML Simple

<a href="/users/edit/5">Modifier</a>

✅ Tag Helper

<a asp-action="Edit" 
   asp-controller="Users"
   asp-route-id="5">
  Modifier
</a>

asp-items

Lier une liste aux options

❌ HTML Simple

<select>
  <option>...</option>
</select>

✅ Tag Helper

<select asp-for="@Model.RoleId" 
    asp-items="@(new SelectList(Model.Roles, "Id", "Name"))">
</select>

asp-validation-for

Afficher les messages de validation

❌ HTML Simple

<span class="error">...</span>

✅ Tag Helper

<span asp-validation-for="@Model.Email" 
    class="text-danger"></span>

asp-append-version

Ajouter une version aux ressources

❌ HTML Simple

<link href="/css/style.css?v=123" />

✅ Tag Helper

<link href="/css/style.css" 
    asp-append-version="true" />

💡 Conseils et Bonnes Pratiques

✅ Préférer les Tag Helpers

Les Tag Helpers (ASP.NET Core) sont plus modernes et lisibles que les HTML Helpers. asp-for est mieux que @Html.TextBoxFor()

✅ Utiliser les expressions Lambda

Les expressions Lambda offrent une meilleure intellisense et refactoring. m => m.Name au lieu de chaînes de caractères

❌ Éviter les URLs en dur

Ne pas écrire href="/users/edit" mais utiliser les helpers asp-action et asp-controller

✅ Toujours valider côté serveur

Même avec la validation HTML5 côté client, valider toujours au serveur avec ModelState.IsValid

✅ Utiliser DisplayNameFor pour les labels

Cela utilise les attributs [Display(Name="...")] du modèle, rendant la maintenance plus facile

❌ Ne pas oublier @Html.AntiForgeryToken()

Toujours inclure le token CSRF dans les formulaires POST pour la sécurité
