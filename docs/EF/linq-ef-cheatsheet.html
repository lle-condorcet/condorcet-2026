📚 LINQ with Entity Framework

Cheatsheet complète - Toutes les opérations essentielles

🔍 SELECT - Projection et Récupération

Récupérer tous les enregistrements

Retourne une liste complète

var users = await _db.Users.ToListAsync();

Récupérer le premier élément

Retourne un seul objet ou null

var user = await _db.Users
    .FirstOrDefaultAsync();

Projection avec Select

Transformer les données

var names = await _db.Users
    .Select(u => u.Name)
    .ToListAsync();

Projection en objet anonyme

Créer une nouvelle structure

var result = await _db.Users
    .Select(u => new { u.Id, u.Name })
    .ToListAsync();

Récupérer distinctement

Éliminer les doublons

var countries = await _db.Users
    .Select(u => u.Country)
    .Distinct()
    .ToListAsync();

Récupérer un nombre spécifique

Limiter les résultats

var top5 = await _db.Users
    .Take(5)
    .ToListAsync();

🔎 WHERE - Filtrage

Filtrage simple

Une condition

var adults = await _db.Users
    .Where(u => u.Age >= 18)
    .ToListAsync();

Filtrage avec AND (&&)

Plusieurs conditions

var result = await _db.Users
    .Where(u => u.Age >= 18 && u.IsActive)
    .ToListAsync();

Filtrage avec OR (||)

Une condition ou l'autre

var result = await _db.Users
    .Where(u => u.Role == "Admin" 
               || u.Role == "Manager")
    .ToListAsync();

Filtrage par chaîne de caractères

Recherche textuelle

var result = await _db.Users
    .Where(u => u.Name.Contains("John"))
    .ToListAsync();

Filtrage avec StartsWith/EndsWith

Vérifier le début/fin

var result = await _db.Users
    .Where(u => u.Email.EndsWith("@gmail.com"))
    .ToListAsync();

Filtrage avec liste (IN)

Vérifier si dans une liste

var ids = new [] { 1, 2, 3 };
var result = await _db.Users
    .Where(u => ids.Contains(u.Id))
    .ToListAsync();

🔗 INCLUDE & JOIN - Relations

Include - Eager Loading

Charger les données liées

var users = await _db.Users
    .Include(u => u.Orders)
    .ToListAsync();

Include imbriqué

Relations à plusieurs niveaux

var users = await _db.Users
    .Include(u => u.Orders)
    .ThenInclude(o => o.Items)
    .ToListAsync();

Inner Join

Fusionner deux tables

var result = await _db.Users
    .Join(_db.Orders,
        u => u.Id,
        o => o.UserId,
        (u, o) => new { u, o })
    .ToListAsync();

Left Join avec SelectMany

Inclure tous même sans relation

var result = await _db.Users
    .SelectMany(u => u.Orders.DefaultIfEmpty(),
        (u, o) => new { u, o })
    .ToListAsync();

Lazy Loading avec virtual

Charger à la demande

public class User {
    public int Id { get; set; }
    public virtual List<Order> Orders { get; set; }
}

📊 ORDER - Tri

Trier en ordre croissant

Ordre A à Z, 0 à 9

var sorted = await _db.Users
    .OrderBy(u => u.Name)
    .ToListAsync();

Trier en ordre décroissant

Ordre Z à A, 9 à 0

var sorted = await _db.Users
    .OrderByDescending(u => u.Age)
    .ToListAsync();

Tri multiple

Tri secondaire avec ThenBy

var sorted = await _db.Users
    .OrderBy(u => u.Country)
    .ThenBy(u => u.Name)
    .ToListAsync();

Tri avec Skip et Take

Pagination

var page2 = await _db.Users
    .OrderBy(u => u.Id)
    .Skip(10)
    .Take(10)
    .ToListAsync();

Tri avec reverse

Inverser l'ordre

var reversed = await _db.Users
    .OrderBy(u => u.Name)
    .Reverse()
    .ToListAsync();

Aléatoire

Ordre aléatoire

var random = await _db.Users
    .OrderBy(u => EF.Functions.Random())
    .ToListAsync();

🎯 GROUP BY - Regroupement

Regroupement simple

Grouper par une propriété

var grouped = await _db.Users
    .GroupBy(u => u.Country)
    .ToListAsync();

foreach (var group in grouped) {
    Console.WriteLine(group.Key);
}

Compter par groupe

Nombre d'éléments par groupe

var counts = await _db.Users
    .GroupBy(u => u.Country)
    .Select(g => new {
        Country = g.Key,
        Count = g.Count()
    })
    .ToListAsync();

Regroupement avec agrégation

Sum, Average, Min, Max par groupe

var stats = await _db.Users
    .GroupBy(u => u.Department)
    .Select(g => new {
        Dept = g.Key,
        AvgAge = g.Average(u => u.Age),
        TotalSalary = g.Sum(u => u.Salary)
    })
    .ToListAsync();

Regroupement multiple

Grouper par plusieurs colonnes

var grouped = await _db.Users
    .GroupBy(u => new { u.Country, u.City })
    .ToListAsync();

Filtrer après regroupement (Having)

Filtrer les groupes

var result = await _db.Users
    .GroupBy(u => u.Country)
    .Where(g => g.Count() > 5)
    .Select(g => new {
        Country = g.Key,
        Count = g.Count()
    })
    .ToListAsync();

📈 AGGREGATE - Opérations d'Agrégation

Compter

Nombre total d'enregistrements

var count = await _db.Users
    .CountAsync();

// Avec filtre
var adults = await _db.Users
    .CountAsync(u => u.Age >= 18);

Somme

Additionner les valeurs

var total = await _db.Orders
    .SumAsync(o => o.Amount);

Moyenne

Calculer la moyenne

var avgAge = await _db.Users
    .AverageAsync(u => u.Age);

Minimum et Maximum

Valeurs extrêmes

var minAge = await _db.Users
    .MinAsync(u => u.Age);

var maxSalary = await _db.Users
    .MaxAsync(u => u.Salary);

Vérifier l'existence

Any() et All()

var hasAdmins = await _db.Users
    .AnyAsync(u => u.Role == "Admin");

var allActive = await _db.Users
    .AllAsync(u => u.IsActive);

Première valeur existante

First vs FirstOrDefault

// Lance exception si rien
var first = await _db.Users
    .FirstAsync();

// Retourne null si rien
var firstOrNull = await _db.Users
    .FirstOrDefaultAsync();

✏️ INSERT, UPDATE, DELETE

Insérer un enregistrement

Ajouter une nouvelle ligne

var newUser = new User {
    Name = "John",
    Email = "john@example.com"
};

_db.Users.Add(newUser);
await _db.SaveChangesAsync();

Insérer plusieurs enregistrements

AddRange()

var users = new List<User> {
    new User { Name = "Alice" },
    new User { Name = "Bob" }
};

_db.Users.AddRange(users);
await _db.SaveChangesAsync();

Mettre à jour un enregistrement

Modifier et sauvegarder

var user = await _db.Users
    .FirstOrDefaultAsync(u => u.Id == id);

if (user != null) {
    user.Name = "Jane";
    await _db.SaveChangesAsync();
}

Mise à jour en masse

Modifier plusieurs enregistrements

var users = await _db.Users
    .Where(u => u.Country == "USA")
    .ToListAsync();

foreach (var user in users) {
    user.IsActive = true;
}

await _db.SaveChangesAsync();

Supprimer un enregistrement

Supprimer et sauvegarder

var user = await _db.Users
    .FirstOrDefaultAsync(u => u.Id == id);

if (user != null) {
    _db.Users.Remove(user);
    await _db.SaveChangesAsync();
}

Supprimer plusieurs enregistrements

RemoveRange()

var inactive = await _db.Users
    .Where(u => !u.IsActive)
    .ToListAsync();

_db.Users.RemoveRange(inactive);
await _db.SaveChangesAsync();

🚀 Requêtes Avancées

Raw SQL

Exécuter du SQL natif

var users = await _db.Users
    .FromSqlInterpolated(
        $"SELECT * FROM Users WHERE Age > {age}")
    .ToListAsync();

Include avec Where

Filtrer les relations chargées

var users = await _db.Users
    .Include(u => u.Orders
        .Where(o => o.Total > 100))
    .ToListAsync();

Union de deux requêtes

Combiner deux LINQ

var query1 = _db.Users
    .Where(u => u.Role == "Admin");

var query2 = _db.Users
    .Where(u => u.IsVIP);

var combined = await query1
    .Union(query2)
    .ToListAsync();

Intersection

Éléments communs à deux requêtes

var active = _db.Users
    .Where(u => u.IsActive);

var premium = _db.Users
    .Where(u => u.IsPremium);

var result = await active
    .Intersect(premium)
    .ToListAsync();

Except

Éléments d'une requête sauf l'autre

var allUsers = _db.Users;
var banned = _db.Users
    .Where(u => u.IsBanned);

var active = await allUsers
    .Except(banned)
    .ToListAsync();

Utiliser des variables (LINQ to Objects)

Combiner client et serveur

var ids = new[] { 1, 2, 3 };
var users = await _db.Users
    .Where(u => ids.Contains(u.Id))
    .ToListAsync();

// Filtrage client après
var filtered = users
    .Where(u => u.Orders.Any())
    .ToList();

⚡ Optimisation de Performance

Éviter N+1 Queries

Mauvais ❌ vs Bon ✅

❌ Mauvais

var users = await _db.Users
    .ToListAsync();

foreach (var user in users) {
    // 1 query par user!
    var orders = user.Orders;
}

✅ Bon

var users = await _db.Users
    .Include(u => u.Orders)
    .ToListAsync();

// 1 seule query!

AsNoTracking

Lecture seule, plus rapide

var users = await _db.Users
    .AsNoTracking()
    .ToListAsync();

// Entity Framework n'a pas besoin
// de tracker les changements

Select avant ToList

Réduire les données transférées

// Mauvais - toutes les colonnes
var users = await _db.Users
    .ToListAsync();

// Bon - seulement ce qu'il faut
var names = await _db.Users
    .Select(u => u.Name)
    .ToListAsync();

Pagination efficace

Skip et Take au serveur

int pageSize = 10;
int pageNumber = 2;

var users = await _db.Users
    .OrderBy(u => u.Id)
    .Skip((pageNumber - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();

Split Query

Plusieurs queries au lieu d'une complexe

var users = await _db.Users
    .Include(u => u.Orders)
    .Include(u => u.Addresses)
    .AsSplitQuery()
    .ToListAsync();

ExecuteUpdate (EF Core 7+)

Mise à jour sans charger les données

await _db.Users
    .Where(u => u.Country == "USA")
    .ExecuteUpdateAsync(x =>
        x.SetProperty(u => u.IsActive, true));

// Pas besoin de SaveChanges()

💡 Conseils et Pièges Courants

✅ Toujours attendre les async

Utilisez await avec ToListAsync(), FirstOrDefaultAsync(), etc.

❌ Éviter les boucles LINQ

Faire le filtrage au serveur avec Where(), pas en C# après ToList()

✅ Utiliser AsNoTracking()

Pour les requêtes de lecture seule, ça améliore les performances

❌ Problème N+1 Queries

Toujours utiliser Include() pour charger les relations associées

✅ SaveChangesAsync()

Toujours sauvegarder avec async, ne pas bloquer le thread

❌ Éviter ThenInclude excessif

Trop de ThenInclude = requête SQL très complexe et lente
